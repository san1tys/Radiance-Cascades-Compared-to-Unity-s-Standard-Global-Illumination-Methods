# Radiance Cascades vs. Unity's Standard Global Illumination Methods

Experimental materials for the DIGRA conference paper:

> **"Comparative Evaluation of Real-Time Global Illumination Methods in Unity URP"**

## Contents

- **Raw datasets**: FPS and frame time measurements
- **Figures**: all figures used in the paper
- **Render videos**: recordings for visual comparison are available in the [YouTube playlist](https://www.youtube.com/watch?v=daDjPJyB86o&list=PLaHv1eGKS6CyZF2IG05RV7KAHvvU5-xIQ)

## Test Environment

| Component | Specification |
|-----------|---------------|
| Engine    | Unity 6000.2.12f1 (URP) |
| GPU       | NVIDIA RTX 4060 Laptop GPU |
| CPU       | Intel Core i7-13620H |
